# pokemon-nazonazo-game

ポケモンのなぞなぞゲーム（全80問）。ブラウザで開くだけで遊べます。

## あそびかた

- **なぞなぞスタート**: 4択のなぞなぞ。ステージのぼんやりした姿が、正解すると現れます
  - 💡 ヒントは1問につき3回まで（最初の文字 → 文字数 → 選択肢を2つ消す）
  - 連続正解でコンボボーナス（最大+10点）。ヒント3を使うと5点になります
  - 間違えた問題は「にがてふくしゅう」に貯まり、正解すると卒業できます
- **タイムアタック**: 60秒で何問解けるか挑戦。結果はランキング（上位10件）に保存
- **ずかん**: 解いたポケモンがコレクションできます。解いたポケモンはタップで再挑戦

## 機能

- 効果音とBGMつき（どちらもブラウザ内で生成）。右上の 🔊/🔇 ボタンでオン/オフ
  - 音オフにすると完全に止まります。画面を離れたときも自動で止まり、戻ると再開します
- 進捗（ずかん・スコア・にがてリスト）とランキングはブラウザの localStorage に保存
- メニュー下の「データを リセット」から最初からやり直せます
